# TS-BLITZ 〜5分でWebアプリをデプロイせよ〜

TypeScript をまだ書いたことがない人が、**1回5分以内のプレイ**で
「TS の書き方」「Web アプリ開発に必要な道具」「人に説明できる知識」をまとめて体験できるブラウザゲームです。

▶ **今すぐ遊ぶ：https://kopi-developed.github.io/ts-blitz-game/**

インストールは不要です。PC のブラウザ（Chrome / Edge など）で開いて、キーボードだけで遊べます。

---

## 起動方法

1. 上の URL をブラウザで開く
2. 日本語入力を **OFF（半角英数）** にする
3. **Enter**（または PLAY ボタン）で本編スタート。**F** でフリープレイ

| キー | できること |
| --- | --- |
| Enter / Space | スタート・次へ進む |
| 1〜4 | 選択肢を選ぶ |
| Esc | 一時停止（ゲーム中）／戻る |
| D | 開発スタック図鑑を開く |
| A | リザルト画面で、直したアプリを触る |
| M | ミュート（タイトル画面） |

スコア・図鑑・苦手な問題の記録は、使っているブラウザの中（localStorage）に保存されます。

---

## どんなゲーム？

画面の右側には、エラーで止まった小さなアプリがあります。
4 つのウェーブを進めると、このアプリが少しずつ直っていき、最後に本番公開（デプロイ）されます。

直すアプリは 5 種類。毎日「今日のアプリ」が変わり、タイトル画面の **← →** で好きなアプリに切り替えられます。

| アプリ | 種類 | 直すと学べる型の書き方（例） |
| --- | --- | --- |
| MiniTask | タスク管理（Todo） | 配列・関数の型・`Promise<T>`・イベントの型・`unknown` |
| MiniGuess | 数当てゲーム | 型の絞り込み・タプル・判別可能な Union・`as const` |
| MiniWallet | 家計簿 | `Record`・`Omit`・省略可能な項目（`?`）・`readonly` |
| MiniPomodoro | ポモドーロタイマー | `ReturnType<typeof setInterval>`・`keyof typeof`・`satisfies`・useEffect の後片付け |
| MiniJanken | じゃんけんバトル | Union の手・`Record<Hand, Hand>` の勝ち表・タプル・`never` の網羅チェック |

| ウェーブ | 内容 | 身につくこと |
| --- | --- | --- |
| 1. 型タイピング防衛（60秒） | 迫ってくる「ランタイムエラー虫」を、TS のコードをタイプして倒す。3体目からは型の部分を隠した穴埋め | `string` / `number[]` / Union型 / `interface` / ジェネリクスなどの書き方 |
| 2. スタック装備バトル（60秒） | 「入力を検証したい」などのお題に合う道具を選び、コードを打って装備する | Vite・React・Zod・tsconfig・ESLint など、TS 以外に必要な道具の役割 |
| 3. ライブアプリ修復（75秒） | コードの `???` や `any` を正しい型に直すと、選んだアプリの機能が 1 つずつ動き出す | アプリごとの型の書き方（上の表）、`any` が危ない理由 |
| 4. 最終審査ボス戦（45秒） | CTO の質問に 4 択で答えて、デプロイの承認をもらう | 「なぜ TS を使うのか」を人に説明する力 |

- **爽快感**：コンボ（x2 / x4 / FEVER）、レベルアップ、効果音、画面の揺れやパーティクル
- **解説**：正解のあとに「なぜそうなるか」が出ます。読んでいる間はタイマーが止まります
- **地図**：「準備 → 型 → 画面 → データ → 見た目 → チェック → 公開」の 7 ステップのうち、いまどこの話かを表示します
- **リザルト**：ランク（S / A / B）、「今日、人に説明できる3行まとめ」（コピーできます）、図鑑に登録されたツール
- **完成したアプリを触れる**：リザルト画面で **A**。Wave 3 で直した機能だけが本当に動くアプリを、実際に使ってみられます（タイマーには早送りボタン付き）

### フリープレイ（時間制限なし・スコアなし）

タイトル画面で **F**。次の 5 ジャンルから選んで、好きなだけ解けます。
本編やフリープレイで間違えた問題ほど、多く出題されます。

- 型タイピング
- 道具選び
- 修復（5 つのアプリから出題）
- ファイル配置（このコードは `types/`・`hooks/`・`components/` のどこに置く？ Expo と Vite の両方）
- 説明力

## 使っている技術

Vite / React / TypeScript（`strict: true`・`any` 禁止）/ Tailwind CSS / lucide-react / Web Audio API（効果音はすべてその場で合成）

このリポジトリには、公開用にビルドしたファイルだけが入っています（自動で更新されます）。

## プライバシー

アクセス解析・広告・Cookie は使っていません。スコアや図鑑の記録は、遊んでいるブラウザの中（localStorage）にだけ保存され、外には送られません。
